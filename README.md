# Charkyve

Successor to the repository previously published as **`splippers/charkive`** (now **Charkyve**).

## Repository rename (GitHub)

If you still have the old remote:

1. In GitHub: **Settings → General → Repository name** → set name to **Charkyve** (or create a new repo and push here).
2. Update your local remote:

```bash
git remote set-url origin git@github.com:splippers/Charkyve.git
```

Use `https://github.com/splippers/Charkyve.git` instead if you use HTTPS.
